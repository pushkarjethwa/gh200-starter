# Contoso Support Portal — GH-200 Demo

Tiny dependency-free Node.js application used to demonstrate a continuous GitHub Actions story:

1. Module 1 — workflow fundamentals + custom container action
2. Module 2 — CI, matrix testing, logs, artifacts, environment variables
3. Module 3 — deployment environment, secrets, conditions, Azure App Service, artifact cleanup, status badge

Local commands:

```bash
npm ci
npm test
npm run build
npm start
```
